Simulation settings and limitations
The workflow requests a start every five minutes. Each active session samples approximately once per minute; there are gaps between sessions, and GitHub can delay jobs. The actual timestamps and sampling gaps are saved. This is an observation experiment, not a sub-second trading system.
Paper entries use a later observed book and only price levels present in both snapshots, with reduced quantity and an adverse price buffer. This stress scenario is not calibrated fill probability. It cannot model competing orders, exchange acknowledgements, queue priority, or the market impact of your hypothetical orders.
All statistics here concern simulated money. Forecast learning, 7 AM calls, drift, weather alerts, and existing scorecards run separately and are not changed by this add-on.
