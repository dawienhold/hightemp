How this number is built

Settlement truth is the CLI daily climate report each station's NWS office issues overnight — the MAXIMUM line, in whole °F. Everything here aims at that number, not at a grid cell near the station.

Two calibrations, doing different jobs. The bias term is the station's reported high minus each model's own analysis over the trailing month, which captures the offset between the grid and the actual sensor. The skill term comes from what each model really forecast a day ahead, and it alone sets the width of the confidence interval — analysis error would understate the spread badly, because the analysis has already seen the weather.

Intraday the observations take over. Each model's running error against today's readings is carried forward with a three-hour decay, the forecast can never fall below what has already been reported, and the interval narrows on both how little heating day is left and how much rise the models still expect. A day locks in only once the temperature is falling and no model still reaches above the observed maximum.

Feed cadence. KMIA, KMDW, KLAX and KSFO transmit every ~5 minutes in whole °C, so a single reading carries about ±0.9°F of slack; the hourly METAR tenths and the 6-hourly remark group pin it precisely, and both are used when present. KNYC transmits hourly only — its card carries the note.

Which day a reading belongs to. The CLI's climate day runs midnight to midnight local standard time. While daylight time is in force that is 1:00 AM to 1:00 AM on the wall clock, so a reading at 12:30 AM belongs to the previous day's report. Every observed maximum on this page is filed that way. Only a final CLI (issued after the day closes) settles a call; the afternoon preliminary report never does.

Sources: api.weather.gov, aviationweather.gov and open-meteo.com. Raw METARs, every call and every settlement are archived in the repository's docs/data folder.
